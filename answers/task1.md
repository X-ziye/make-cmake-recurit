# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理：预处理器处理源代码中以#开头的指令。比如把#include的头文件内容插进来，展开#define宏，根据条件编译保留或删除部分代码，并去掉注释。输出仍然是源代码，通常生成.i文件。
2. 编译：编译器对预处理后的代码进行词法、语法和语义分析，检查错误，并做一定优化，然后把它翻译成汇编代码，通常生成.s文件。
3. 汇编：汇编器会将上一阶段翻译的汇编代码进一步转为CPU可直接识别的二进制机器码，通常生成.o文件。但函数和变量的地址还没有确定，无法独立运行。
4. 链接：链接器将多个目标文件和所需的库合并，解析符号的引用并确定各函数和变量的真实地址，最终生成可执行文件。

建议控制在 300～500 字，不需要展开复杂细节。
